## Cosa impari

9 lezioni progressive su due moduli:

**Modulo 1 — Python per il ML**
- Lezione 1: Variabili e tipi di dato *(gratuita)*
- Lezione 2: Funzioni e cicli
- Lezione 3: Liste e dizionari avanzati
- Lezione 4: NumPy — calcolo numerico veloce
- Lezione 5: Pandas — analisi di dataset reali

**Modulo 2 — Matematica per l'AI**
- Lezione 6: Algebra lineare
- Lezione 7: Calcolo e gradient descent
- Lezione 8: Probabilità e teorema di Bayes
- Lezione 9: Statistica per ML

## Come usarlo

```bash

# Opzione 2 — clona la repo
git clone https://github.com/neuramente/aipro-fase1
cd aipro-fase1
```

## Caratteristiche tecniche

- **Zero dipendenze runtime** — singolo file HTML da ~300KB
- **localStorage** per il tracking del progresso tra sessioni
- **jsPDF** per la generazione del certificato nel browser
- **CSS @media print** per output stampabile
- **Fullscreen API** — premi `F` per il viewer a schermo intero
- **Light/dark mode** con preferenza salvata
- **Freemium** — Lezione 1 gratuita, resto con licenza
