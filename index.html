Lezione 3 · Algebra Lineare
Cosine Similarity —
come GPT capisce le parole

Nei modelli linguistici, ogni parola è un vettore. La cosine similarity misura quanto due vettori puntano nella stessa direzione...

# distanza tra embeddings
def cos_sim(a, b):
  return np.dot(a,b) / (
    norm(a) * norm(b))
# → 0.994 (re ≈ regina)
